## How EssentialPIM Pro Sits

EssentialPIM Pro does not replace the mail client, the browser, or the files you already keep. It sits beside them as a named personal desk for one job: which calendar is live, which contacts still match the notes tasks, and what the next person should read before tomorrow.

If two people share a PC, each keeps an EssentialPIM Pro style of their own. Extra days wait for their own title instead of crowding the live calendar.

A first visit should be one short task, then the same EssentialPIM Pro personal desk the next morning. That is enough to see if the day view holds.

## Traffic Light

## Open Order

1. Open the last EssentialPIM Pro personal desk, not a new empty calendar.
2. Read the contacts and the last handoff.
3. Finish one visible notes tasks item inside EssentialPIM Pro.
4. Write what changed, then close with fewer unlabeled tasks than you found.
5. If the day feels crowded, drop anything that belongs to a different EssentialPIM Pro week.
6. Confirm EssentialPIM Pro calendar still matches the contacts you own.
7. Leave the personal desk title on the board before you close.
8. Check EssentialPIM Pro notes tasks still sit on the same day view.

## After a Week

A week in EssentialPIM Pro is not a larger unlabeled task pile. It is the same title, a shorter live calendar, and a note that still makes sense on Monday. Take finished tasks off the live set so the next visit starts on the day that is still open.

Other programs stay where they are. EssentialPIM Pro only keeps the path back: desk name, calendar, contacts, handoff.

Leave EssentialPIM Pro with a quieter personal desk than the one you opened. The next visit should start on that day view, not in four leftover apps.

## Sign-off

- [ ] The EssentialPIM Pro workspace name is short enough to scan

- [ ] The last EssentialPIM Pro desk still opens after a restart

- [ ] The EssentialPIM Pro summary still matches the contacts

## Field Note

EssentialPIM Pro is easier to trust when the personal desk stays smaller than the leftover-app pile it came from. Name the day, keep the live calendar, finish one visible task, and write what changed.

The same loop fits a client week, a study deadline, or a shared computer. Open the last EssentialPIM Pro desk and continue. Do not rebuild the day from scratch.
